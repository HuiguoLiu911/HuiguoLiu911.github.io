The question

A March 2026 side project: could I get a fitness tracker with an AI coach running in the browser, starting from a Google AI Studio scaffold and finishing it by hand?

Data

None shipped. Workouts are stored in the browser through a local storage service, so nothing leaves the device except the coach prompts.

Method

React 19 with Vite and TypeScript. Eight components cover onboarding, dashboard, workout logger, date filter, history, stats with recharts charts, layout and the AI coach. A Gemini service built on @google/genai turns the logged history into training advice rendered as markdown. The API key lives in an uncommitted local env file.

Results

  • Working tracker: log a workout, see progress charts, review history, ask the coach about your own log.

What it changed

A learning exercise in taking an AI Studio export to a maintainable TypeScript codebase and wiring a Gemini call into a front end.

Limitations and next steps

Browser-only storage means no sync across devices, and the coach is only as good as the logged data. Next steps: CSV export and a small backend if I want it on my phone.

Code & materials

The code lives in a private GitHub repository (HuiguoLiu911/fitgenius). Access on request — send me a note.
